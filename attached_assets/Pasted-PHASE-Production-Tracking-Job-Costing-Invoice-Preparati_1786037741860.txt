PHASE: Production Tracking, Job Costing, Invoice Preparation, and Executive Reporting

Objective:

Extend the application from field reporting and billing validation into a complete production and job-costing platform.

The app must allow contractors to compare:

- Work completed
- Work billed
- Labor used
- Equipment used
- Materials used
- Estimated revenue
- Estimated cost
- Gross margin
- Missing production
- Unapproved billing
- Project performance

The system should help foremen, supervisors, billing staff, project managers, and company leadership understand whether work is being documented, charged, reviewed, and prepared for invoicing correctly.

Do not remove, rebuild, or break existing:

- Authentication
- Company onboarding
- Company isolation
- Crews
- Employees
- Projects
- Daily reports
- Labor entries
- Equipment entries
- Material entries
- Work-package templates
- Charge sheets
- Billing rules
- Missing-charge detection
- Undercharge detection
- Approval workflows
- Audit history
- Mobile responsiveness
- Existing user data

Before implementation:

1. Inspect the current codebase and database schema.
2. Identify existing models that can be extended.
3. Reuse existing business logic.
4. Create safe database migrations.
5. Preserve all historical reports and charge-sheet versions.
6. Run the existing test suite.
7. Fix existing blocking bugs before adding new features.
