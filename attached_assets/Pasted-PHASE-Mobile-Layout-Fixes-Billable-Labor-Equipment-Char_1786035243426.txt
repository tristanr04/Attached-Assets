PHASE: Mobile Layout Fixes, Billable Labor, Equipment Charges, and Reusable Crew Templates

Objective:

Fix the current mobile usability problems and build a complete billable labor and equipment system.

The app must allow companies to configure their own labor classifications, equipment, rates, billing codes, and reusable crew setups. Foremen should be able to select people and equipment quickly instead of entering the same information every day.

Do not remove or break existing authentication, company setup, crew management, projects, reports, database records, or role permissions.

Before changing code:

1. Inspect the current application structure.
2. Review the current database schema.
3. Identify the onboarding and mobile layout problems.
4. Reuse existing models and components where appropriate.
5. Create database migrations instead of resetting or deleting existing data.

## 1. Fix the Mobile Layout Across the Entire App

The current interface does not fit smaller phone screens correctly.

Audit every page and fix all mobile responsiveness issues.

Requirements:

- No horizontal scrolling.
- No content wider than the viewport.
- Forms must fit properly on iPhone and Android screens.
- Cards must shrink and stack vertically.
- Buttons must remain fully visible.
- Inputs must not extend beyond the screen.
- Tables must convert into mobile-friendly cards or stacked rows.
- Modals must fit inside the viewport.
- Navigation must remain usable on small screens.
- Respect device safe areas, including notches and the bottom home indicator.
- Account for the mobile keyboard opening.
- Do not allow fixed elements to cover inputs or buttons.
- Use large tap targets appropriate for gloved or outdoor use.
- Keep text readable without requiring zoom.
- Avoid excessive empty space.
- Keep the most important actions visible near the top.

Test at minimum:

- 320px width
- 375px width
- 390px width
- 430px width
- Tablet width
- Desktop width

Specifically review and fix:

- Create Company page
- Login and registration
- Dashboard
- Crew setup
- Project setup
- Daily report forms
- Equipment selection
- Labor entry
- Review and submission pages
- Admin settings

## 2. Create a Company-Specific Billable Item System

Create a flexible billable-item catalog that belongs to each company.

A company administrator must be able to create and manage its own billing structure.

Billable item categories must include:

- Labor
- Equipment
- Materials
- Work units
- Add-on charges
- Custom categories

Each billable item should support:

- Company ID
- Category
- Item name
- Description
- Billing code
- Internal code
- Customer or contract
- Unit type
- Base rate
- Overtime rate
- Double-time rate
- Emergency rate
- Storm rate
- Quantity
- Default quantity
- Taxable status if needed
- Active or inactive status
- Effective date
- Expiration date
- Notes
- Created by
- Created timestamp
- Updated timestamp

Rates and codes must remain private to the company that created them.

Do not hard-code one company’s rates into the application.

## 4. Daily Labor Entry

On a daily report, allow the foreman to add multiple workers.

Each labor entry should support:

- Employee
- Classification
- Regular hours
- Overtime hours
- Double-time hours
- Storm hours
- Travel hours
- Per diem days
- Other billable labor
- Notes
- Billing code
- Calculated charge

The app should automatically calculate the charge using the company’s configured rates.

The foreman must be able to edit hours but should not need to manually enter the rate every day.

Display a clear breakdown:

- Regular labor charge
- Overtime labor charge
- Double-time labor charge
- Per diem
- Other labor charges
- Total labor charge

Do not expose employee pay rates unless the company administrator explicitly configures and permits that data.

Billing charge rates and employee wages must be treated as separate concepts.
